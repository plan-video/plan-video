Post to X with text, pictures or a video.

## What you can post

| | Limit |
| --- | --- |
| Text | 280 characters |
| Pictures | Up to 4, 5 MB each |
| Video | Up to 1 GB, and up to 5 minutes in plan.video |

## Good to know

- **Paid plans only.** X charges for posting through its API, so X is available from the Creator plan.
- **Posts a month.** X charges plan.video for every post, and far more for a post with a link, so each plan posts to X up to a set number of times in any 30 days, and fewer of those can have a link:

  | | Posts to X | With a link |
  | --- | --- | --- |
  | Creator | 150 | 10 |
  | Pro | 400 | 25 |
  | Agency | 800 | 40 |

  These count every X account you've connected together. A post past either limit isn't sent, and its error says when there's room again. To send one past the link limit, take the link out and post it again.
- **Links include bare addresses.** A post counts as having a link when it has a web address in it, with or without `https://`, such as `plan.video`.
- **50 posts a day.** You can post to X up to 50 times a day. A post past that waits, and goes out on its own once there's room.
