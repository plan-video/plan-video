**Bulk tools** turns a batch of files into posts in one go, on paid plans. Find it under **Schedule** in the dashboard.

<Steps>
  <Step title="Add your files">
    Drop in up to 50 files, or click **From library**. Each file becomes its own post or story: an MP4 or MOV of up to 5 minutes, or a JPG or PNG.
  </Step>
  <Step title="Apply to many at once">
    Select posts, then use **Apply to** to set the accounts, post them as posts or stories, and write a caption they share. A caption can use `{name}`, `{n}` and `{date}`, so each post gets its own.
  </Step>
  <Step title="Choose when">
    Space them out every so many days or hours, with **Skip weekends** if you like. Or give them the next free times in [Auto-schedule](/docs/scheduling#auto-schedule), or your [best times](/docs/analytics#post-at-your-best-times).
  </Step>
  <Step title="Send them off">
    Click **Schedule # posts** (or **Auto-schedule # posts**), **Save as drafts** or **Post now**.
  </Step>
</Steps>

Stories go to Instagram and Facebook, with no caption.

## Import captions from a spreadsheet

**Import captions** → **Import CSV** fills in posts from a file. It matches rows to files you've already added, by file name, so add the files first. A row with no matching file is skipped.

| Column | | Example |
| --- | --- | --- |
| `file` | Required | `launch.mp4` |
| `caption` | | `We're live!` |
| `date` | | `2026-10-01`, `2026/10/01` or `01-10-2026` (day first) |
| `time` | | `9:00`, `09:00` or `9pm` |
| `platforms` | | `tiktok, youtube` |

Columns can be separated by commas, semicolons or tabs.
