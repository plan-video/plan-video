## Vault

The **Vault** keeps words you reuse, each with a name:

| Kind | For |
| --- | --- |
| Captions | Whole captions |
| Hashtags | Sets of hashtags |
| Snippets | Anything shorter, like a call to action |

Click **New** to add one. It warns you if it's too long for a network. In a post, drop one into the caption from the **Vault** button, or click **Use in post** from the Vault itself.

### Signature

Choose **Use as signature** on a Vault item, and new posts end with it. You can leave it off any one post.

## Templates

A **template** is a post set up once, ready to start from: its accounts, caption, settings for each network, follow-ups and when it goes out. You bring the media.

- **Make one:** click **New** on the **Templates** page, or in **New post** open **Templates** and choose **Save as template…**.
- **Use one:** click **Use** on the template. It opens as a new post, and changing it there leaves the template as it was.

A template's **Goes out** can be **No set time**, a set time, or **Next queue slot**.
