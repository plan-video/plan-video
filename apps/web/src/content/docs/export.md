Save your video as a file to keep it or post it somewhere else.

## Formats

| Format | Good for |
| --- | --- |
| MP4 | Posting anywhere |
| MOV | Editing in other apps |
| WebM | The web |

You can also set the resolution, bitrate, codec, frame rate and audio.

## Quality

| Plan | Highest quality |
| --- | --- |
| Free | 1080p |
| Paid plans | 4K at 60 fps |

<Tip>
You don't need to export to post. Attach the project to a new post and plan.video exports it for you.
</Tip>
