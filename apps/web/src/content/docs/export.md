Save your video as a file to keep it or post it somewhere else.

## Formats

| Format | Good for |
| --- | --- |
| MP4 | Posting anywhere |
| MOV | Editing in other apps |
| WebM | The web |
| OGG | Audio only |

Click **Export** to pick a preset, like **Full HD**, **YouTube Shorts** or **TikTok**, or set the resolution, bitrate, codec, frame rate and audio yourself.

<kbd>⌘</kbd> <kbd>E</kbd> exports at the default Full HD. <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>E</kbd> saves the current frame as a picture.

## Quality

| Plan | Highest quality |
| --- | --- |
| Free | 1080p |
| Paid plans | 4K at 60 fps |

<Tip>
You don't need to export to post. Click **Schedule post** in the editor, or attach the project to a new post, and plan.video exports it for you as an MP4 at 1080p. For higher quality, export it yourself and add the file to the post.
</Tip>
