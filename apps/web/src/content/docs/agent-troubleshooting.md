<AccordionGroup>
  <Accordion title="The agent says plan.video isn't open">
    Your agent's requests run through your plan.video tab. Open [plan.video](https://plan.video) in a browser, sign in, and ask again.
  </Accordion>
  <Accordion title="The sign-in page doesn't open">
    Some agents only sign in when you ask. In Claude Code, run `/mcp` and pick *planvideo*. In Codex, run `codex mcp login planvideo`. In other agents, look for a sign-in or authenticate option next to the server.
  </Accordion>
  <Accordion title="The agent can't find my video">
    Agents can only attach files in your [media library](/docs/media-library). Upload the file there, then ask again.
  </Accordion>
  <Accordion title="A post was saved but didn't go out">
    Check that it has a time and isn't a draft. Then look under **Posts** → **Failed**. See [Failed posts](/docs/failed-posts).
  </Accordion>
  <Accordion title="The agent says a network isn't supported">
    Pinterest can be planned but not sent yet. See [Coming soon](/docs/coming-soon).
  </Accordion>
  <Accordion title="I want to start over">
    Disconnect the agent under **MCP & CLI** → **Connected apps**, remove plan.video from the agent, and [connect it again](/docs/connect-an-agent).
  </Accordion>
</AccordionGroup>
