<AccordionGroup>
  <Accordion title="The agent says plan.video isn't open">
    Your agent's requests run through your plan.video tab. Open [plan.video](https://plan.video) in a browser, sign in, and ask again.
  </Accordion>
  <Accordion title="The agent says I didn't confirm">
    plan.video asks you in your open tab before an agent publishes, deletes or schedules, and no answer in time counts as no. Keep the tab where you can see it, and ask again.
  </Accordion>
  <Accordion title="The tab didn't answer in time">
    The tab may be in the background or still at work. Bring it to the front, check what was done, then ask again.
  </Accordion>
  <Accordion title="Too many calls in a minute">
    An agent can make 120 calls a minute. Wait a moment and ask it to go on.
  </Accordion>
  <Accordion title="It won't publish a post with two accounts on one network">
    Publishing through an agent sends one account per network. Schedule the post instead, or leave one account on it.
  </Accordion>
  <Accordion title="The sign-in page doesn't open">
    Some agents only sign in when you ask. In Claude Code, run `/mcp` and pick *planvideo*. In Codex, run `codex mcp login planvideo`. In other agents, look for a sign-in or authenticate option next to the server.
  </Accordion>
  <Accordion title="The agent can't find my video">
    Agents can only attach files in your [media library](/docs/media-library). Upload the file there, then ask again.
  </Accordion>
  <Accordion title="A post was saved but didn't go out">
    Check that it has a time and isn't a draft. Then look for it under **Failed**. See [Failed posts](/docs/failed-posts).
  </Accordion>
  <Accordion title="The agent says a network isn't supported">
    Pinterest can be planned but not sent yet. See [Coming soon](/docs/coming-soon).
  </Accordion>
  <Accordion title="I want to start over">
    Disconnect the agent under **Connected apps** on the dashboard's [**MCP & CLI** page](https://plan.video/dashboard?dashboard=mcp), remove plan.video from the agent, and [connect it again](/docs/connect-an-agent).
  </Accordion>
</AccordionGroup>
